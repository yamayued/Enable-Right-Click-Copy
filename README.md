# 絶対右クリックできるくん (Super Copy Extension)

すべてのウェブサイトで右クリック、コピー、選択、貼り付けを有効にするChrome拡張機能です。

## 主な機能

### 🔓 制限解除機能
- **右クリックメニュー**: 無効化されている右クリックを強制的に有効化
- **テキスト選択**: 選択不可のテキストを選択可能に
- **コピー機能**: コピー禁止を解除
- **貼り付け機能**: 貼り付け制限を解除
- **キーボードショートカット**: Ctrl+C、Ctrl+V、Ctrl+A などを有効化

### ⚙️ カスタマイズ機能
- **個別機能の有効/無効切り替え**: ポップアップUIから各機能を個別に制御
- **サイトごとの設定保存**: ドメインごとに異なる設定を記憶
- **ワンクリック設定**: 現在のサイトの設定をワンクリックで保存

### 🛡️ 強化された保護回避
- JavaScriptイベントハンドラーの無効化
- CSS制限の解除
- 動的に追加される制限の継続的な監視と解除
- インラインスクリプトの制限解除

## インストール方法

1. Chromeの拡張機能管理ページ（`chrome://extensions/`）を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダを選択

## 使い方

1. **自動有効化**: 拡張機能をインストールするだけで、すべてのサイトで機能が有効になります

2. **設定のカスタマイズ**:
   - 拡張機能アイコンをクリックしてポップアップを開く
   - 各機能のトグルスイッチで有効/無効を切り替え
   - 「このサイトの設定を保存」ボタンで現在の設定を記憶

3. **サイトごとの設定**:
   - 各サイトで異なる設定を保存可能
   - 保存した設定は次回訪問時に自動的に適用

## 技術仕様

- **Manifest Version**: 3
- **権限**: activeTab, scripting, storage
- **対応サイト**: すべてのウェブサイト（`<all_urls>`）

## 注意事項

- 一部のサイトでは、セキュリティ上の理由から機能が制限される場合があります
- 銀行サイトなど、高度なセキュリティが必要なサイトでは慎重に使用してください
